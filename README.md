# Professional Portfolio Website

A responsive student portfolio website built with **HTML, CSS, and JavaScript** for the course assignment due **01 August 2026**.

## Features

- Professional one-page design
- Responsive desktop, tablet, and mobile layout
- Mobile navigation menu
- Light and dark mode
- Scroll reveal animation
- Active navigation highlight
- Project category filters
- Front-end contact form validation
- LocalStorage theme preference
- No framework required

## Project Files

- `index.html` — page structure and content
- `style.css` — layout, colors, responsive design, and animation
- `script.js` — navigation, theme, filters, scroll effects, and form validation
- `demo-script.txt` — short video demonstration script
- `SUBMISSION-CHECKLIST.txt` — final assignment checklist

## Run the Website

### Easy method

Double-click `index.html` to open it in a browser.

### VS Code method

1. Open the folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Upload to GitHub

1. Create a new GitHub repository named `professional-portfolio`.
2. Open this folder in VS Code.
3. Open Terminal and run:

```bash
git init
git add .
git commit -m "Create professional portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/professional-portfolio.git
git push -u origin main
```

Your source code URL will be:

`https://github.com/YOUR-USERNAME/professional-portfolio`

## Deploy with GitHub Pages

1. Open your repository on GitHub.
2. Click **Settings**.
3. Select **Pages** from the left menu.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Click **Save**.
7. Wait until GitHub shows the live website link.

Your deployment URL will usually be:

`https://YOUR-USERNAME.github.io/professional-portfolio/`

## Alternative Deployment with Vercel

1. Sign in to Vercel using GitHub.
2. Click **Add New Project**.
3. Import the `professional-portfolio` repository.
4. Leave the default settings.
5. Click **Deploy**.
